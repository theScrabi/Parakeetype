Parakeetype - безкоштовний застосунок з відкритим кодом для перетворення мовлення на текст на Android. Він працює як голосова клавіатура і як служба розпізнавання мовлення для всієї системи.

Усе розпізнавання відбувається виключно на вашому пристрої за допомогою моделі Parakeet Ultra (додатково навченої версії Parakeet-TDT v3 від NVIDIA) через ONNX Runtime - жоден звук не залишає телефон, обліковий запис не потрібен, а застосунок зовсім не має доступу до інтернету.

<b>Можливості</b>

• Клавіатура для перетворення мовлення на текст: диктуйте в будь-яке текстове поле
• Служба голосового введення: інші застосунки, як-от перекладачі, Firefox чи Duolingo, можуть використовувати Parakeetype для голосового введення
• Дуже швидко: модель залишається завантаженою в пам'ять, тож розпізнавання починається одразу
• Розпізнавання повністю на пристрої - цілковита приватність
• Без дозволу на інтернет: один раз завантажте файл моделі в браузері та імпортуйте його
• Без Google Play Services, Firebase чи сторонньої телеметрії
• Мінімум дозволів: мікрофон, сповіщення, служба переднього плану

<b>На основі Outspoke</b>

Parakeetype - форк застосунку Outspoke, доповнений новими можливостями.

<b>Вимоги</b>

• Android 12 (API 31) або новіший
• ~630 МБ вільного місця для файлу моделі
• Модель завантажується окремо з релізів проєкту на GitHub та імпортується в застосунку (CC-BY-4.0)
